# javushka-2 (Gradle, Java 21)

Minimal Java project layout using Gradle and Java 21.

## Project structure

- `src/main/java` - application source
- `src/test/java` - tests (JUnit 5)

## Run

```bash
./gradlew run
```

## Test

```bash
./gradlew test
```

Add your classes under `src/main/java/<your/package>/`.
